About This Project

ParliDebate AI is built to help citizens and researchers analyze parliamentary debates using AI.

🎯 Our Mission

Make parliamentary debates transparent and accessible by using AI to summarize, analyze sentiment, and identify key arguments.

✏️ Project Motive

Citizens often can't follow complex political debates. This tool breaks them down into clear, understandable insights.

🔧 How It's Built

Frontend: HTML, CSS, JavaScript. Backend: Node.js + Express. AI Engine: Google Gemini 1.5 Flash (multimodal).

🛡️ Ethical AI

No data is stored. All uploads are processed and deleted immediately. The AI provides analysis, not opinion.

⚙️ Key Technologies

Google Gemini API (text, vision, audio, video), Multer (file handling), Express.js, Vanilla JS.

👤 About the Developer

Built as a B.Tech project to promote political awareness through AI-powered analysis tools.
